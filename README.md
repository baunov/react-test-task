Онлайн-курс криптовалют в реальном времени

Цель:
Реализовать приложение, которое показывает **текущий курс выбранной криптовалюты к USDT** в реальном времени, используя **публичный WebSocket API от Binance**.

Условия задачи:

- **Можно** гуглить, использовать любые библиотеки.
- **Нельзя** пользоваться AI

1. На старте загружаются все доступные торговые пары с Binance API: GET https://api.binance.com/api/v3/exchangeInfo

- Отфильтровать пары с `status === "TRADING"` и `quoteAsset === "USDT"`
- Пример пары: `btcusdt`, `ethusdt`

2. Реализовать выпадающий список (`<select>`) для выбора пары

3. После выбора пары, приложение должно:

- Подключиться по WebSocket к Binance
- Отобразить **текущую цену** в формате `$29250.01`
- Обновлять цену в **реальном времени** (при каждом сообщении)

4. Отображать:

- Имя пары (например `BTC/USDT`)
- Текущую цену
- Цвет: **зелёный**, если цена выросла, и **красный**, если упала
- Если цена прежняя, отображать прежний цвет
- Статус `Загрузка...`, пока цена не получена

WebSocket URL:
wss://stream.binance.com:9443/ws/{symbol}@trade

Пример:  
`wss://stream.binance.com:9443/ws/btcusdt@trade`

Ответ:

{
"e": "trade",
"s": "BTCUSDT",
"p": "29250.01"
}

5. Компоненты/стили (дизайн не важен)
- здесь для удобства присутствует Tailwind и Shadcn (select и button)
- но можно использовать и нативные HTML/CSS
